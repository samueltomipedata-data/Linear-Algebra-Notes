# MIT 18.06 Linear Algebra — Notes

Personal notes from working through Gilbert Strang's MIT 18.06 Linear Algebra
course, taken as I build toward a career in data science and machine learning.

Started: late July 2026

## Why I'm doing this

Linear algebra is the math underneath most of ML — vectors, matrices,
eigenvalues, SVD. This repo is where I turn my handwritten lecture notes
into clean, reviewable summaries, and (eventually) small code
implementations of the core algorithms.
